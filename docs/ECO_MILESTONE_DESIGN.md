## 1. 设计缘起：神锻炉哪些值得学

| 神锻炉机制 | ECO 版取舍 |
|---|---|
| 投料 → 内部电池 → 运行 | ✅ 借鉴"投料驱动"：GUI 投料槽，放够材料升级 |
| 4 条幂律里程碑计量（电/配方/燃料/结构） | ⚠️ 简化：单一"里程碑进度"（累计投料价值），5 级幂律门槛 |
| 碎片货币 → 31 节点升级树 | ⚠️ 简化：不设货币与树，**等级直接解锁**（超小型任务线，用户定位） |
| 反转二周目（全满重开指数增长） | ✅ 可选彩蛋：5 级满后"超频模式"（10% 红线放宽/超线程免额） |
| 大升级材料分步支付（16 格暂存窗口） | ✅ 借鉴：每级材料可分多次投（进度累计，非一次性） |
| 统计预览面板 | ✅ 借鉴：GUI 里程碑进度条 + 解锁内容列表 |
| 31 节点大树 / 3 环巨型结构 / 无线 EU | ❌ 不做（§7.3 不推荐项） |

核心模型 = **投料 → 里程碑进度 → 等级 → 解锁**（三层中最简形态）。

## 2. 系统概览

```
┌─ ECO 存储阵列（1 台，替代 L4/L6/L9）── 3 条主线 ──┐
│   物品线：物品盘分级 k→M→大M                        │
│   流体线：流体盘分级 k→M→大M                        │
│   源质线：源质盘分级 k→M→大M（依赖 TE4）            │
├─ ECO 计算主机（1 台，替代 C4/C6/C9）── 1 主线+2 支线 ──┤
│   主线：晶阵类型 k→M→大M→16384M→全量（自动升级）    │
│   支线 A：并行核心 1..65536（自主投料）              │
│   支线 B：线程核心 1→4→16→超线程 2/4→8（自主投料）  │
└───────────────────────────────────────────┘
投料：GUI 选线投料（按钮切换投给哪条线，各线进度条同屏）
不可重设（投了不退）；初始 = 最低档（Lv1）
```

- **档位概念移除**：控制器注册名唯一化；旧 `_c4/_c6/_c9`、`_l4/_l6/_l9` 注册名废弃（存档迁移走 FML 缺失 ID 流程）
- 里程碑等级持久化在机器 NBT（重启保留）

## 3. 里程碑机制

### 3.1 投料（GUI 选线投料）
- 控制器 GUI 新增**投料区**（MUI1 量子计算机同款面板内）：**选线按钮**（当前投给哪条线）+ 各线**进度条**同屏显示
- 投料材料（混合线，随等级提升）：
  - GT 线：铁→铝→钛→铱→中子素→恒星物质（阶段递进）
  - AE 线：处理器→电路板→逻辑处理器→存储元件（点缀）
- 每次投入 → 所选线进度 += 材料价值 → 进度满 → **该线升级**（聊天提示 + GUI 横幅）
- **不可重设**（用户拍板：投了不退、不可重分配）

### 3.2 等级与幂律门槛（5 级）
- 每线门槛 = 累计投料价值（幂律递增：Lv2=1×、Lv3=4×、Lv4=16×、Lv5=64× 相对 Lv1→2 的基准）
- 材料可分多次投（进度累计，不要求一次放够——神锻炉分步支付精神）

### 3.3 反转彩蛋（可选，用户拍板是否要）
- 全部线满级 → 解锁"超频模式"：10% 字节红线放宽至 5% / 超线程 +10% 免额（神锻炉反转奖励语义）

## 4. 解锁表

### 4.1 计算主机（每级解锁 = 该级及以下全部可用）

| 等级 | 主线·晶阵 | 支线A·并行核心 | 支线B·线程核心 |
|---|---|---|---|
| Lv1（初始） | k 级（256k/1024k/4096k） | 1 / 4 / 16 | 1 |
| Lv2 | M 级（16M/64M/256M） | 64 / 256 | 4 |
| Lv3 | 大M（1024M/4096M） | 1024 / 4096 | 16 |
| Lv4 | 大M（16384M） | 16384 | 16 + 超线程 2 |
| Lv5 | 全部 | 65536 | 16 + 超线程 4/8 |

- **门控（用户拍板：接受等级门控）**：并行/线程核心物品由"全档自由"改回**等级门控**——驱动器 `isItemValidForSlot`/`interactWithCore` 按**对应线的里程碑等级**校验（Lv1 插不了 65536 核心；晶阵同理按主线等级）
- 容量上限：字节池可用上限随主线等级提升（Lv1 限制 k 级池 → Lv5 全量）

### 4.2 存储阵列（用户拍板：物品/流体/源质 3 条主线，容量自然累加维持现状）

每条线独立投料升级，解锁对应类型的盘分级：

| 等级 | 物品线 | 流体线 | 源质线 |
|---|---|---|---|
| Lv1（初始） | k 级盘 | k 级盘 | k 级盘 |
| Lv2 | M 级盘 | M 级盘 | M 级盘 |
| Lv3 | 大M 盘（1024M/4096M） | 大M 盘 | 大M 盘 |
| Lv4 | 大M 16384M | 大M 16384M | 大M 16384M |
| Lv5 | 全盘 | 全盘 | 全盘 |

- 容量无人工上限（总字节 = Σ插入盘容量，与现状一致——用户决策 C）
- 源质线依赖 TE4 加载（既有门控）；初始各线 Lv1（仅 k 级盘）

## 7. 工作量与风险

**工作量估计**：15~25 人日（分阶段：里程碑框架 → 计算主机改造 → 存储阵列改造 → GUI/配方/迁移 → 打磨）
- 涉及：物品门控重构、GUI 投料、里程碑逻辑、注册/配方、存档迁移、文档

**风险与行为变化**：
1. **并行/线程核心从"全档自由"改回等级门控**（与之前拍板相反——里程碑系统需要门控才有意义；需用户确认接受）
2. 档位合并 → 老档位机器/物品存档迁移（FML 自动处理 + 备份，E-Storage 已有先例）
3. 平衡：投料材料量与门槛数值需实测调优（先按基准出，装机后调）
4. 与 AE 终端显示联动：vCPU 等级标记（M3/M4）改显示里程碑等级
