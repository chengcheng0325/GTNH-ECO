# 07 · TECTECH_STANDARD — TecTech 深海军蓝（品牌皮肤）

- 主题 ID：`tectech:standard`（GTGuiThemes.TECTECH_STANDARD，parent = STANDARD）
- 背景纹理：`screen_blue.png`（90×72 角块，2px 灰边，terminal 背景）+ `screen_blue_no_inventory.png`（190×171 整面板）+ `tectech_logo.png`（18×18）

## 配色（实测）
- terminal 背景填充：深海军蓝黑 `#000020`，边框灰 `#808080`
- logo：亮蓝 `#0072FF` + 白高光
- 数据行：标签灰 GRAY / 名称青 AQUA / 数字金 GOLD（TecTech 特色）
- 参数条五色：蓝 `#428AFF`、青 `#03DEFF`、绿 `#52FF42`、橙 `#FFD142`、红 `#FF4242`

## 风格一句话
深海军蓝黑底 + 灰细边 + 蓝霓虹数据，TecTech 全系机器的标志性皮肤。

## 适用（现用机器）
TecTech 所有机器（TTMultiblockBase 默认 getGuiTheme）：量子计算机、有源变压器、BEC 系列（组装机/存储/二极管/IO节点）、EyeOfHarmony、DataBank、特斯拉塔、无线能量舱/计算舱等。

## 备注（本项目相关）
t24 已为 ECO 176×128 面板给出完整 TecTech 配色规范；若用户选此主题，ECO 控制器把 terminal 底换成 screen_blue 系即可。
