# 08 · GORGE — Godforge 神铸（TecTech 变体）

- 主题 ID：`gorge`（GTGuiThemes.GORGE，parent = TECTECH_STANDARD）
- 背景纹理：同 TECTECH（`screen_blue.png` / `screen_blue_no_inventory.png`）；按钮用 Godforge 专用纹理（`gregtech:button_gorge`）

## 与 TECTECH_STANDARD 的差异
- 按钮/开关换成 Godforge 专属纹理（GORGE 主题仅覆盖 button/simpleToggleButton）

## 风格一句话
TecTech 深蓝皮肤 + 神铸专属按钮。

## 适用（现用机器）
Godforge（Forge of Gods）及其模块（熔融/等离子/异形/冶炼模块，MTEBaseModule.getGuiTheme → GORGE）。
