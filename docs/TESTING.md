- [ ] 创造栏可见 `ECO 存储阵列源质盘 (16M/64M/256M)`，**气体盘已消失**

### C. 多方块成型（原无法成型）
1. 放置控制器 **面朝东**（面对东侧放置）
2. 结构（最短 1 列，最长 12 列，列数 = 驱动盘位数量）：
   - 控制器在结构最东侧；驱动列在控制器**西侧（身后）**
   - 每列：z=0 面放 3 个驱动盘位（上中下），z=1 面放 2 电容 + 1 通风口（中）
   - ME 总线在控制器**前右角**（相对 (1,0,1)）
   - 外壳封顶/封底/封边
3. 外壳任意位置可放 **GT 能量舱**（LV-HV）
4. 验证：
   - [ ] 结构成型（控制器 GUI 显示 Structure: Valid）
   - [ ] 用 StructureLib 投影工具右键控制器可预览结构（IConstructable 已实现）

5. 功能：
