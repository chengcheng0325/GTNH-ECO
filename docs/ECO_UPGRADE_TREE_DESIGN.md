# ECO 升级树系统设计（神锻炉同款，无货币版）

> 状态：用户拍板（替代里程碑系统）。参考：docs/GTNH_FORGEOFTHEGODS_RESEARCH.md（神锻炉升级树/里程碑机制）。
> 用户决策：去掉里程碑投料等级；只留升级树——前置依赖 DAG、**分支全可选**（非三选一）、节点=材料提交解锁、**无货币**（无碎片）；GUI 套神锻炉升级树（三层窗口）；基础节点免费；存储阵列也走升级树；约 15 节点。

---

## 1. 核心模型

```
节点 = 一项能力（晶阵档/并行档/线程档/超线程/超频/盘分级）
规则：前置依赖（激活 A 才能提交 B）+ 材料成本（GT+AE 混合，分步支付）+ 激活即解锁
无货币、无等级、无进度条——投料提交 → 节点激活 → 门控放行
```

- 激活状态持久化在机器 NBT
- 门控：驱动器 `isItemValidForSlot` 按**节点激活**校验（对应档位节点激活才允许插入）
- 初始：基础节点免费激活（k 级晶阵 / 1·4·16 并行 / 1 线程 / k 级盘）

## 2. 计算主机升级树（17 节点，3 免费）

```
晶阵链：N1 k级★ → N2 M级 → N3 大M(1024M/4096M) → N4 16384M → N5 全量
并行链：P1 1/4/16★ → P2 64/256 → P3 1024/4096 → P4 16384 → P5 65536
线程链：T1 1★ → T2 4 → T3 16
超线程：H1 2（前置 T2）→ H2 4（前置 T3）→ H3 8（前置 T3 + P3）
超频：  OC 超频模式（前置 N5 + P5 + T3 + H3）→ 红线 5% + 超线程 +10% 免额
（★ = 免费基础节点）
```

## 3. 存储阵列升级树（12 节点，3 免费）

```
物品链：I1 k级★ → I2 M级 → I3 大M → I4 16384M
流体链：F1 k级★ → F2 M级 → F3 大M → F4 16384M
源质链：E1 k级★ → E2 M级 → E3 大M → E4 16384M
（每链独立，互不依赖；源质链需 TE4 加载）
```

## 4. 材料成本（每节点，混合线）

- GT 线：铁→铝→钛→铱→中子素→恒星合金（随节点深度递增）
- AE 线：处理器→电路板→逻辑处理器→存储元件（点缀）
- **分步支付**（神锻炉 MANUAL_INSERTION 模式）：16 格暂存窗口 + 已付数量（红/黄/绿）+「消耗材料」提交按钮
- 具体每节点材料清单：装机后按材料表（MaterialValue 已有）与节点深度定，实现时先占位常量

## 5. GUI 三层（MUI1，神锻炉同款结构）

| 层 | 窗口 | 内容 |
|---|---|---|
| 1 | **升级树总览**（主入口按钮，id 300） | 滚动树：节点按钮（图标+激活/可提交/未解锁状态色）+ 连接线（依赖连线）；左键节点=详情；已激活节点高亮 |
| 2 | **节点详情**（id 301） | 名称/描述/前置需求/材料需求列表（已付/需求）/「材料投入」按钮 |
| 3 | **材料投入**（id 302） | 材料需求槽 + 已付数量 + 16 格投料暂存窗口 + 「消耗材料」提交按钮（PAY 模式，材料扣减+节点激活+聊天提示） |

- 入口：主面板右侧按钮列（里程碑按钮 → **升级树总览**；原"升级"按钮并入——按钮列调整）

- 超频节点激活 → GUI 标记 + 聊天提示
